## How the rules are read

The scoring engine (`packages/scoring`) and the build (`packages/pipeline`) read some rules of this version in a way the text above does not spell out. Each reading applies to every country alike.

- **"Most severe" is chosen by points.** Where only one measure of an indicator counts (B8, B12, C1, C4 and D3), the measure with the most points is kept, not the one with the most points multiplied by its confidence weight. A severe measure supported only at confidence reported therefore counts at its reduced weight even when a milder confirmed measure of the same country would weigh more. When a B5 and a B6 position start on the same day, the one whose event id sorts last holds.
- **States and values that began before 7 October 2023 count from 7 October 2023.** A standing state or a computed value dated earlier is scored from the first day of the window.
- **A standing state lifts the passivity penalty for 365 days from its start.** The passivity rule looks for a qualifying event dated in the 365 days up to the date; the date of a standing state is its start date. A state that still holds after 365 days keeps its points but no longer lifts the penalty. This includes the pre-existing recognition of Palestine (B8, +3 from 7 October 2023), which lifts the penalty until 5 October 2024. Negative events qualify too: the rule counts the absolute value of the contribution.
- **A1 when a SIPRI release is in force.** A release covers every country: a country that delivered nothing to Israel in its data year has s = 0, so A1 is none-found and scores 0. Before the first release after 7 October 2023 (11 March 2024), A1 is no-data for every country. While no SIPRI release has been imported, A1 from that date keeps the status of the hand-written assessment.
- **Coverage is published for the build date only.** The assessments record what was checked, not the date from which it applied, so the coverage bar and the published coverage are those of the build date, including on a dated page (`?date=`) and in the daily series, which carry scores and no coverage. For the generated indicators (B1, B2, A1, A2, A4, C3 and D1), the status is derived from the structured tables with its reason, in place of a date checked.
- **Two readings of the project specification recorded after this version was written.** The weights a reader can set are four, for categories A to D; the specification's five sliders included E, which is not scored. C3's "at or above the pre-war level" is read as a ratio of at least 0.9 to the 2022 total.
- **The name of D1.** In version 1.0.0-rc.1 the name of D1 reads "scaled per capita of GNI". The formula divides funding by the country's total GNI, x = F ÷ GNI, as the section on computed indicators states. The name is corrected in the next version of the wording, through the change procedure described under Versioning and changelog.

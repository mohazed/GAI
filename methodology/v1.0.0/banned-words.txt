# banned-words.txt — tone lint for the site's own voice
# Gaza Accountability Index, methodology v1.0.0
#
# Purpose
# Event summaries, EN and FR, contain none of the terms below (docs/02 §12.6, docs/05 §7,
# CLAUDE.md "Site voice"). A summary states a fact: {Actor} {past-tense verb} {object}{, qualifier}.
# No judgement adjectives, no editorial adverbs, no legal characterisations in the site's own words.
# The same list is applied, as a warning, to other text written in the site's voice (rule
# tone.site-voice).
#
# Scope
# Only the site's own voice is linted. Quotes are evidence and are never linted: a quote may
# contain any of these words, verbatim and attributed to its speaker.
#
# Format
# UTF-8, one term per line. Lines starting with # are comments; blank lines are ignored. A term
# line holds the term and nothing else (no trailing comment).
#
# Matching
# - Case-insensitive. Terms and text are compared after Unicode NFC normalisation.
# - Whole words only: a match is never preceded or followed by a letter or a digit (\p{L}, \p{N}),
#   so a term never matches inside a longer word ("courage*" does not match "encouraged").
#   Hyphens, apostrophes (' and ’), spaces and punctuation are not letters: "anti-zionist" is
#   caught by "zionis*".
# - Multi-word phrases are allowed. A space in a phrase matches any run of whitespace, including
#   U+00A0 and U+202F. The apostrophes ' and ’ match each other, so a phrase is listed once.
# - A trailing * means "any word starting with": "honteu*" matches honteux, honteuse, honteuses,
#   honteusement. It is the only wildcard. In a phrase it applies to the last word ("war crime*"
#   matches "war crimes"). A prefix term is used only where no neutral word a summary could need
#   starts with it; otherwise the exact forms are listed ("lâche*" would match "lâcher", "dive*"
#   would match "divest", "barbar*" would match "Barbara", "sauvage*" would match "implantations
#   sauvages", "appal*" would match "Appalachian").
# - Every term applies to both the EN and the FR summary. Where one entry covers both languages
#   (same spelling, or one prefix), it is listed once, under "EN + FR".
#
# Deliberately not listed (neutral terms the summaries need)
# genocide, génocide (Genocide Convention, the ICJ case); court, crime, criminal, criminel
# (International Criminal Court); occupation, occupied, occupying power; settlement, settler,
# colonie, colon, colonisation; blockade, blocus; ceasefire, cessez-le-feu; famine, starvation;
# violation; sanction; embargo; veto; unconditional, inconditionnel (the B10 wording "unconditional
# support"; "unconditional release of all hostages" in Security Council resolutions); terrorism,
# terrorisme (statute names, e.g. the Terrorism Act 2000 under which a proscription is an E2
# event); regime, régime as a bare word (legal name of sanctions, export-control and trade
# frameworks: "sanctions regime", "régime de sanctions", "régime préférentiel"; only the phrases
# that apply it to a government are listed); indiscriminate, disproportionate, collective
# punishment, human shields, hostage-taking (conduct defined in international humanitarian law,
# named in B9 statements, like "starvation as a method of warfare"); extraordinary, extraordinaire
# (institutional meeting names); catastrophe (the name of IPC Phase 5); alleged (legal hedge);
# deplored, condemned, commended, welcomed, regretted (verbs that report what the actor did).
#
# Changes
# This file is part of the methodology. It changes only through a new methodology version folder
# and a CHANGELOG.md entry (docs/08 §1), never in place.
